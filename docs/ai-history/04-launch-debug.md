# 04 · 线上排障：用事实推翻三次猜测

> 时间：2026-10-21 上午
> 对应提交：`1024b88` `d95eec8`
> 本文档是整个项目里**最能体现人机协同排障**的一段，建议重点阅读。

## 第一关：首页 404

> 用户：在我让你修改这个文件之前我就已经把这个项目部署到服务器上了，域名也准备好了，但是现在打开网页显示 404。

AI 先 `git fetch` 对照远端，得到硬事实：

```
远端 HEAD = c64d896（与本地一致）→ 代码已推
远端 index.html 路径 = public/index.html  → 根目录已无 index.html
```

结论直接得出：**项目「输出目录」仍是根目录，而首页已经移进 `public/`**。

接着给出一个不花时间的自检法：

> 打开 `https://域名/public/index.html`。能打开 → 确认是输出目录配错；也 404 → 是产物没生成。

用户回复「能打开页面」——**假设被验证**。

过程中还遇到一个次生问题：

> 用户：我找不到重新部署在哪，改完设置只有一个保存。

AI 给出绕行方案：**推一个空提交触发构建**（`git commit --allow-empty`）。这比在陌生控制台里找按钮更快。

## 第二关：`fetch is not defined`

> 用户：好了打开了，但现在我试了一下快捷键，显示调用通义千问万相失败。

AI 先要求**原话**，而不是接受转述：

> 底部状态栏那行红字，完整复制给我。

拿到四个字：`fetch is not defined`。

### 一次被自己否定的推断

AI 先猜"Node 版本太低"，判断依据是"health 能跑、换装挂了，而 health 不用 fetch"。

但用户说：`我现在的 node 版本是 22.11.0`。

AI 没有就此收手，而是做了三件事：

1. **加诊断字段**（提交 `1024b88`）：`/api/health` 返回 `node`、`has_fetch`、`has_abort_signal_timeout`、`api_key_length`、`dashscope_host`，并把 `err.cause.code` 拼进错误信息（`fetch failed` 本身没有信息量）
2. **本地复现**：`delete globalThis.fetch` 后调阿里云，确认抛的就是这个错
3. **写不依赖结论的修复**（提交 `d95eec8`）：新增 `_lib/net.js`，**有 fetch 用 fetch，没有就退回 `node:https`**

第三条是关键取舍：

> 即使我还没 100% 确认根因，也要让修复**在两种假设下都成立**。

实测两种环境都能打通阿里云（用不存在的模型名试探，返回 400 `Model not exist`，证明请求真的发出去了，且不产生费用）。

## 第三关：环境变量

> 用户：（截图）报错了 …… 不对不对，不是这个问题，他的提示是未配置环境变量。

AI 直接从外部探测线上接口（只读，不消耗额度）：

```bash
curl /api/health   → api_key_configured: true, api_key_length: 115
curl /api/tryon    → 能打到阿里云并返回业务错误（说明 2D 正常）
curl /api/create3d → "3D 服务不可用，已切换演示模型：未配置 TRIPO_API_KEY"
```

一秒钟定位：**2D 的 Key 配了，3D 的 Key 没配**。

这里体现的判断是：**当用户描述模糊时，用可观测的接口输出代替反复追问**。

## 第四关：缓存造成的假象

用户贴回的 `/api/health` 是旧结构，看起来像"新代码没部署"。AI 加随机参数重查：

```bash
curl "https://aitry.online/api/health?v=$RANDOM"
→ tripo_face_limit: 30000   ← 新版本其实已经上线
```

响应头 `Cache-Control: no-store`、`EO-Cache-Status: Cache Miss` 佐证没有被缓存。

> 教训：**控制台的"已部署"和边缘节点的"已生效"之间有时间差**，验证必须带缓存破坏参数。

## 阶段小结

| 猜测 | 结局 |
|---|---|
| "输出目录配错" | ✅ 被 `/public/index.html` 可访问验证 |
| "Node 版本太低" | ❌ 被 `node: v20.19.3` 推翻，但修复对两种情况都有效 |
| "环境变量没配" | ✅ 被三个接口的对比输出确认 |

**方法论沉淀**：先拿事实（接口输出、响应头、git 远端状态），再谈原因；诊断字段先埋进代码，比反复问用户更快。
