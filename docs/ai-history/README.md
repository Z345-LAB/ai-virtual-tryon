# AI 协同开发记录（Prompt 快照）

本目录是「次元造物」项目在开发过程中，人与 AI 协同的**核心对话与决策记录**，用于满足第九届传智杯「AI创新应用挑战赛」对 **AI 对话历史 Prompt 快照** 的要求。

## 记录原则

1. **只记真实发生过的**。用户原话直接引用会话原文（已做去敏处理，去掉密钥、手机号等），不做润色。
2. **重点记录「人怎么引导」和「AI 怎么判断」**，而不是仅记录代码结果——这是本赛道的考察重点：*AI 编写代码，人类引导意图*。
3. 每一条都对应 **一个 Git 提交** 或一次可验证的实验结果，便于交叉核对。

## 协同方式说明

- **人的职责**：定义产品目标、拍板取舍（是否花钱、是否改方案）、在真机/真实网络下验证、最终推送代码。
- **AI 的职责**：读代码、定位问题、写实现、跑真实接口验证、给出可执行的排查路径。
- **关键约定**：所有推送由人工执行（AI 不代推），保证提交节奏由人把控、历史真实。
